# 计算机网络 — 从掌握到精通

面向**后端 + Agent 开发**的计算机网络学习体系。不按大学教材从物理层线性铺开，而是以工程问题为主线：TCP、HTTP、流式通信、排障工具优先，链路层与容器网络按需深入。

本目录按 [goal.md](goal.md) 的规格生成：知识文章讲原理，代码示例跑流程，实验任务用抓包验证——三者互相对应。

## 学习目标

学完这套材料，应当能够：

1. 完整回答"一个 HTTP 请求从客户端到服务器再返回，中间发生了什么"，精确到每一层。
2. 深入理解 TCP 状态机与拥塞控制，看到 `TIME_WAIT`/`CLOSE_WAIT`/`RST` 能直接推断出谁的问题。
3. 说清 HTTP/1.1 → HTTP/2 → HTTP/3(QUIC) 每一步演进解决了什么、代价是什么。
4. 用 Go 写出**正确**的网络程序：分包、分层超时、取消传播、连接池、优雅关闭。
5. 搞定 Agent 场景的网络问题：LLM 流式输出（SSE）、长连接保活、Webhook 可靠性、SSRF 防护。
6. 独立使用 tcpdump / Wireshark / ss / dig / curl 定位线上网络故障。
7. 亲手实现一个支持流式透传的 HTTP 网关（综合项目 Agent Gateway）。

## 适用人群

- 有 Java/Go 后端基础，网络知识停留在"背过八股"阶段，缺乏体系和动手验证。
- 正在做 Agent/LLM 应用开发，被超时、流式中断、连接泄漏、代理缓冲这类问题困扰。
- 想把"面试会答"升级成"线上敢查"。

## 环境准备

### 基础环境

- **Go 1.22+**（`go version` 确认）
- **本仓库开发机为 Windows 11**，网络实验强烈建议装 **WSL2**（Ubuntu）：`ss`、`tcpdump`、`ip`、`conntrack` 等 Linux 工具是排障章节的主角，PowerShell 只有部分等价物。

### 抓包工具（第一周就装好）

| 工具 | 平台 | 用途 |
|------|------|------|
| Wireshark + Npcap | Windows | 图形化分析：跟踪 TCP 流、看握手/重传/TLS |
| tcpdump | WSL2 / Linux | 命令行抓包，服务器排障的标准工具 |
| curl | 双平台自带 | `-v` 看协议交互，`-w` 分解各阶段耗时 |

⚠️ Windows 安装 Wireshark 时勾选 Npcap（含 loopback 抓包支持），否则抓不到 127.0.0.1 的流量。

### Windows 特有注意事项

- 首次运行监听 `0.0.0.0` 的示例，Windows 防火墙会弹窗，选"允许"，否则局域网可达性实验会得出错误结论。
- PowerShell 等价命令速查：`Test-NetConnection host -Port 443`（≈ telnet/nc）、`Get-NetTCPConnection -State TimeWait`（≈ `ss -t state time-wait`）、`Resolve-DnsName`（≈ dig）。
- 需要"从另一台设备访问本机"的实验（验证监听地址作用域），可用手机连同一 Wi-Fi 代替第二台电脑。

## 实验运行方法

- `code/` 下每个编号目录自包含：进入目录 `go run .`，具体参数看目录内 README 或文件头注释。
- `labs/` 下每个实验给出：目标 → 操作步骤 → 预期观察 → 解释。抓包类实验注明了过滤表达式，直接复制使用。
- 涉及"两端"的实验（server/client）优先在本机双终端完成；明确标注"需要第二台设备"的除外。
