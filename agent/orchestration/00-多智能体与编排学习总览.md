## 1. 四个贯穿专题的心智模型

### 1.1 Workflow/Agent 是控制权连续谱

“workflow 固定、agent 动态”是起点，但真实系统混合两者：代码规定能力、预算、审批和状态转移；模型在允许集合中选择工具、分解任务或 handoff。要逐项问：下一节点、工具、完成判断、重试和停止分别由代码还是模型决定。

### 1.2 拓扑必须附带 ownership

一条 Agent A → Agent B 的边可能表示：

- delegation：A 调 B 做 bounded subtask，A 仍负责最终答案。
- handoff：B 接管当前回复/决策所有权。
- event：A 发布事件，不等待特定 B；需去重、顺序和消费确认。

如果不标答案 owner、active owner、state version 和迟到写规则，拓扑图不能推导系统行为。

### 1.3 Checkpoint 不等于 exactly-once

resume/replay 可能重跑节点；effect 成功但 checkpoint 失败，或 checkpoint 成功但 effect 未发生，都会形成 crash window。可靠恢复需要 activity 边界、idempotency key、receipt 和 `OUTCOME_UNKNOWN` 对账，而不是只打开 checkpointer。

### 1.4 多 Agent 收益必须因果验证

增加 Agent 通常同时增加模型调用、上下文隔离、工具目录变化和 verifier。公平实验要固定模型/工具/预算，比较单 Agent、等预算 Best-of-N、manager、handoff，并分层测 router/handoff/worker/join/coordination/end-to-end。

## 2. 学习顺序

```text
01 节点与组合模式
 ↓ 先回答串行、路由、并行和动态分解的执行语义
02 拓扑与 ownership
 ↓ 再回答谁拥有任务、共享什么、如何隔离故障
03 durable state/replay/HITL
 ↓ 理解崩溃、暂停、重放、并发写和升级
04 本地组合与 A2A 1.0
 ↓ 跨系统时加入 Task/Artifact/身份/版本
05 框架故障选型
 ↓ 用同一 crash/HITL/cancel/migration spike 比较
06 SLO、trace、因果评测与 runbook
```

## 4. 面试追问树

| 层次 | 追问 | 合格回答必须覆盖 |
|---|---|---|
| 定义 | workflow、manager、handoff、event/A2A 有何语义差异？ | 控制权与 answer/task owner，不按拓扑名字判断 |
| 机制 | fan-out/fan-in 怎样定义正确性？ | ALL/ANY/quorum/deadline、work item、join reducer、cancel/late result |
| 反例 | `asyncio.gather` 或 checkpoint 为什么不够？ | 背压/公平/部分失败；replay 与外部 effect crash window |
| 落地 | 并发多 Agent 怎样防双写和旧 worker 复活？ | owner、lease、fencing、CAS、write set、idempotency/receipt |
| 协议 | MCP、Agent-as-Tool、handoff、A2A 如何选？ | 工具供给、本地回复所有权、跨实现 Task/Message/Artifact 生命周期 |
| 评测 | 如何证明多 Agent 带来净收益？ | 同模型/工具/总预算基线、Amdahl、paired ablation、coordination errors |

### 深挖问题清单

1. `asyncio.gather` 为什么不等于正确的并行编排？
2. manager-style 与 handoff 的最终答案 owner 有何差异？
3. checkpoint 恢复为什么可能重复发送邮件？
4. reducer 何时需要结合律、交换律和幂等性？
5. 审批为什么必须绑定 action proposal hash 与 policy version？
6. A2A Message、Task、Artifact 和 `contextId` 分别是什么？
7. SendMessage 超时后为什么不能直接重发？
8. 如何证明多 Agent 的提升不是单纯来自更多 test-time compute？
9. 父任务取消后，已经提交的远程 effect 怎么处理？
10. 框架首页写“persistence”时，你会设计哪组 crash/migration 测试？
