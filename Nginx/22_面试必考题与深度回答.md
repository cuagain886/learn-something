# Nginx 面试必考题与深度回答

## 1. Nginx 为什么高并发

少量 worker 使用非阻塞 fd、epoll/kqueue readiness 和事件状态机，避免每连接线程栈与大量上下文切换；连接对象预分配、buffer chain和批量系统调用降低开销。上限仍受 handler阻塞、CPU、fd、内存和网络约束。

## 2. master/worker 分工

master 解析配置、打开监听/日志/共享内存、fork和管理worker、处理信号；worker降权后执行事件循环和请求。master持有资源使reload可让新旧worker平滑交接。

## 3. reload 为什么能平滑

master构建新cycle成功后fork新worker，旧worker停止accept并排空已有连接。不是原worker原地修改配置。长连接、shutdown timeout、资源不足仍可能造成旧进程长期存在或断流。

## 4. worker_connections 是什么

每worker connection对象上限，包含客户端、upstream等，不是用户请求数。代理常一请求两端连接，还受RLIMIT_NOFILE、内存和HTTP/2 streams影响。

## 5. epoll 是异步I/O吗

主要提供就绪通知：fd可能可读/写。handler仍要实际recv/send并读到EAGAIN。文件AIO/线程池是另一机制。

## 6. location 顺序

先找最长prefix，exact立即结束；若最长prefix带^~跳过相应regex；否则regex按配置顺序首个命中；无regex使用最长prefix。复杂嵌套需逐层分析。

## 7. root 与 alias

root把URI追加到根路径；alias替换location匹配部分。尾斜杠、regex capture和内部rewrite会影响路径，配置错误可能暴露文件。

## 8. proxy_pass 带URI差异

prefix location下带URI会用指定URI替换匹配的规范化前缀；不带URI通常传完整原始/规范化URI。regex、named、变量和rewrite有额外限制，必须按版本测试。

## 9. 三个proxy timeout

connect用于建连，send/read通常是相邻写/读操作间空闲时间，不是总deadline。504常是超时但需用错误阶段和upstream时间确认。

## 10. buffering作用

request buffering隔离慢上传并支持body重放；response buffering尽快释放upstream并隔离慢下载。关闭减少暂存延迟/磁盘，却让背压和连接占用传递到后端。

## 11. upstream keepalive是否限制总连接

通常不是。它限制每worker缓存的空闲连接数，高并发仍可建立更多active连接。

## 12. 重试为何危险

后端可能已执行副作用但响应丢失，Nginx重试另一个peer会重复。非幂等请求需禁用广泛重试并使用业务幂等键。

## 13. cache keys_zone存什么

主要存key metadata和状态，响应body在cache path磁盘。zone大小不是可缓存body容量。

## 14. 如何防缓存击穿

cache lock限制单key并发更新，stale updating/background update让其他请求使用旧值；还需lock timeout、随机过期和后端容量。

## 15. SNI与Host区别

SNI在TLS ClientHello中，握手前选择证书；Host在加密HTTP header中，之后选择HTTP virtual server。二者可不一致，需安全策略。

## 16. HTTP/2是否无队头阻塞

解决HTTP/1.1应用层响应顺序HOL，但多个stream共享TCP，丢包仍阻塞连接字节流。HTTP/3 QUIC把可靠性拆到独立stream，仍共享拥塞和服务器资源。

## 17. limit_req算法

共享zone按key实现漏桶式速率状态，burst吸收突发，nodelay决定立即放行还是排队。多Nginx节点默认不共享全局计数。

## 18. 499是什么

Nginx记录客户端在响应完成前断开。可能是用户取消、前置LB超时、网络或后端太慢，不能简单认为客户端责任。

## 19. 如何定位502/504

结合error log阶段、upstream_addr/status、connect/header/response time和多次尝试序列；区分DNS、connect、TLS、send、header、body与客户端断开。

## 20. 为什么模块不能阻塞

一个worker单线程串行执行事件handler，阻塞库会让该worker所有连接、timer和accept等待。应使用Nginx异步API、线程池支持或外部服务。

## 21. Nginx和L4 LB区别

HTTP层可按Host/URI/header路由、缓存、鉴权和改写；Stream/L4只处理TCP/UDP字节，可用SNI preread但看不到加密URL。L4开销低且协议通用。

## 22. 如何容量规划

用Little定律算in-flight，再计算客户端+upstream连接、fd、每请求buffer/TLS/stream内存、CPU、网络、temp/cache磁盘和N-1容量；压测寻找P99拐点而非只报峰值QPS。
