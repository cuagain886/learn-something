💾 浏览器存储

F12 → Application → Storage 查看存储内容

1. localStorage —— 持久化键值对

⚠️ localStorage 只能存储字符串。存对象需要 JSON.stringify()，取对象需要 JSON.parse()。

2. sessionStorage —— 会话级键值对

💡 API 和 localStorage 一模一样（都是 Storage 接口），区别只在于生命周期。

3. 存储方案对比
