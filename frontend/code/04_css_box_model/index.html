📦 CSS 盒模型 —— 万物皆盒子

每个 HTML 元素都是一个矩形盒子。学会控制盒子的每一层 = 学会布局。

1. content-box vs border-box

两个盒子都写了 width: 300px; padding: 20px; border: 10px，但实际宽度不同：

content-box（默认）

content-box

实际宽度 = 300 + 20×2 + 10×2
= 360px

border-box（推荐）

border-box

实际宽度 = 300px（固定）
内容区自动缩小

💡 建议：在每个项目的 CSS 开头加上：

*, *::before, *::after {
    box-sizing: border-box;
}

3. ⚠️ margin 塌陷（Collapsing Margins）

两个上下相邻的块级元素，margin-bottom 和 margin-top 会"合并"：

margin-bottom: 40px
margin-top: 30px

实际间距 = max(40, 30) = 40px，不是 70px。
用 DevTools 选中元素查看 margin 区域即可确认。

解决方式：

  • 用 Flexbox / Grid 布局（子元素不会塌陷）
  • 给父元素加 border 或 padding（阻断塌陷）
  • 统一只用 margin-top 或 margin-bottom
