📦 ES6 模块化 —— 告别全局变量

模块化 = 每个 JS 文件有自己的作用域，需要显式 export 才能被其他文件使用。

1. 导出（Export）

// ── math.js ──
// 命名导出（可以导出多个）
export const PI = 3.14159;
export function add(a, b) { return a + b; }
export function multiply(a, b) { return a * b; }

// 默认导出（一个模块只能有一个）
export default function sum(...nums) {
    return nums.reduce((a, b) => a + b, 0);
}

2. 导入（Import）

// ── 命名导入（需要知道导出的名字）──
import { add, multiply, PI } from './math.js';

// ── 重命名导入 ──
import { add as myAdd } from './math.js';

// ── 命名空间导入（导入所有命名导出作为一个对象）──
import * as math from './math.js';
math.add(1, 2);  // 3

// ── 默认导入（可以任意命名）──
import sum from './math.js';  // sum 是任意起的名字

// ── 混合导入 ──
import sum, { add, PI } from './math.js';

// ── 只执行模块（不导入任何东西）──
import './init.js';

3. 动态导入 import() —— 代码分割

// import() 返回 Promise，实现按需加载（Lazy Loading）
const module = await import('./heavy-module.js');

// 典型使用场景：路由懒加载
button.addEventListener('click', async () => {
    const { renderChart } = await import('./chart.js');
    renderChart(data);
});
💡 为什么重要？动态 import 是现代前端框架（React/Vue）实现代码分割（Code Splitting）和懒加载的基础。用户只下载当前页面需要的 JS，而不是一次性下载整个应用。

4. 模块的特性

特性说明
严格模式模块自动在严格模式下运行（不需要写 'use strict'）
作用域隔离模块顶层变量不会成为全局变量
静态结构import/export 必须在顶层，不能放在 if/函数内（方便 Tree Shaking）
单例同一个模块被多次 import，只会执行一次（类似 Java 的静态初始化）
异步加载浏览器原生支持，用 <script type="module"> 即可

5. ES Modules vs CommonJS

特性ES ModulesCommonJS (Node.js 旧版)
关键字import / exportrequire / module.exports
加载方式异步（浏览器友好）同步（服务器端 OK）
静态分析✅ 可 Tree Shaking❌ 动态，难分析
使用环境浏览器 + Node.js（.mjs 或 type:"module"）Node.js 默认
导出值的绑定（实时）值的拷贝
💡 现代前端开发中：统一使用 ES Modules。Node.js 22+ 也已完全支持。
