语义化 HTML5 标签速查

标签含义类比（Java）
<header>页头 / 区块头类的顶部注释 + 导入区
<nav>导航链接方法签名区
<main>页面主体（每个页面唯一）main() 方法体
<article>独立内容单元（可被分发/引用）一个独立的 class
<section>文档章节（带主题的分组）class 中的一个方法
<aside>侧边内容（相关但非核心）注释 / 文档中的 "参见"
<footer>页脚类的版权/版本注释
<figure> + <figcaption>图文组合（图片+说明）带 Javadoc 的字段

💡 每天学一点

你不需要记住所有 HTML 标签，知道它们存在就行。 用到时查 MDN 即可。
