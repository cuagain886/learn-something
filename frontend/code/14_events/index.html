3. 常用事件类型速查

类别事件触发时机
鼠标click单击（最常用）
dblclick双击
mousedown / mouseup按下 / 松开
mouseenter / mouseleave进入 / 离开（不冒泡）
mouseover / mouseout进入 / 离开（会冒泡）
键盘keydown按下任意键（最常用）
keyup松开键
keypress按下字符键（已废弃）
input输入框值变化（实时，推荐替代 keydown）
表单submit表单提交（在 form 上监听）
changeselect/file/checkbox 值变化
focus / blur获得 / 失去焦点
focusin / focusout获得 / 失去焦点（会冒泡）
文档DOMContentLoadedDOM 解析完成（早于 window.onload）
scroll / resize滚动 / 窗口大小变化（需节流！）
触摸touchstart / touchend触摸开始 / 结束
touchmove触摸移动
