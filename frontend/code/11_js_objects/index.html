1. 对象字面量 —— 创建对象的标准方式

JS 对象本质上是一个字符串到任意值的映射（类似 Java 的 Map<String, Object>），但语法更简洁。

特性写法说明
属性简写{ name }等同于 { name: name }
方法简写{ greet() {} }等同于 { greet: function() {} }
计算属性名{ [key]: value }key 可以是变量/表达式
属性存在检查key in obj比 obj.key !== undefined 更准确

2. 解构（Destructuring）—— 最实用的语法糖

场景写法
提取属性const { name, age } = user
重命名const { name: userName } = user
默认值const { age = 18 } = user
嵌套解构const { addr: { city } } = user
函数参数function f({ name, age }) {}
剩余属性const { id, ...rest } = obj

3. 展开运算符（Spread）—— 不可变更新

展开运算符 ... 是"不可变数据操作"的核心工具：

操作写法Java 对比
复制对象const copy = { ...obj }浅拷贝（类似 BeanUtils.copyProperties）
合并对象const merged = { ...a, ...b }b 的同名属性覆盖 a
更新属性const updated = { ...obj, age: 30 }创建新对象而非修改原对象
条件属性const o = { ...base, ...(cond && { extra }) }条件性地添加属性
