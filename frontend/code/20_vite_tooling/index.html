⚡ Vite —— 下一代前端构建工具

由 Vue.js 作者尤雨溪开发，是目前前端开发的事实标准。

1. 为什么选 Vite？

⚡
极速冷启动

基于 ESM，不需要打包就能启动开发服务器

🔥
HMR 热更新

修改代码后页面毫秒级更新，不丢失状态

📦
按需编译

只编译浏览器请求的模块

🛠️
开箱即用

TS/JSX/CSS/Sass 无需配置

2. Vite vs Webpack 对比

特性ViteWebpack
开发服务器启动⚡ 即时（ESM native）🐢 需要先打包
HMR 速度极快（与项目大小无关）随项目增大变慢
构建引擎Rollup（高效）自研（复杂）
配置复杂度简单复杂（loader/plugin 体系）
生态成熟度新（2021+）老（2014+，生态最丰富）
使用趋势2024+ 事实标准老项目仍大量使用

3. 项目结构

/项目根目录
├── index.html          ← 入口页面（Vite 要求它在根目录！）
├── package.json        ← 依赖声明 + 脚本（类似 pom.xml）
├── vite.config.js      ← Vite 配置（类似 build.gradle）
├── src/                ← 源代码
│   ├── main.js         ← 应用入口
│   ├── components/     ← 组件
│   └── styles/         ← CSS
├── public/             ← 静态资源（不处理，直接复制到 dist）
└── .env / .env.production  ← 环境变量

4. 常用命令

命令作用Maven/Gradle 对应
npm install安装依赖mvn dependency:resolve
npm run dev启动开发服务器（HMR）mvn spring-boot:run
npm run build构建生产包到 dist/mvn package
npm run preview本地预览生产构建（无直接对应）
npm install --save-dev vite添加开发依赖scope: test
npm install --save lodash添加运行时依赖scope: compile

5. Vite 的特色功能

静态资源导入

// JS 中导入图片（构建后会返回优化后的 URL）
import logoUrl from './logo.svg';

// 导入 JSON（自动解析为对象）
import data from './data.json';

// 导入 CSS（自动注入到页面）
import './style.css';

环境变量

.env                  # 所有环境
.env.development      # npm run dev
.env.production       # npm run build

# 只有 VITE_ 前缀的变量会暴露给客户端
VITE_API_URL=https://api.example.com
💡 与 Java 的对比： Vite 的 .env ≈ Spring Boot 的 application.yml， 但只有 VITE_ 前缀的变量能在前端代码中通过 import.meta.env.VITE_XXX 访问。

6. 下一步：创建你的第一个 Vite 项目

# 使用 Vite 官方脚手架创建项目
npm create vite@latest my-app -- --template vanilla

# 或使用你喜欢的框架模板
npm create vite@latest my-react-app -- --template react
npm create vite@latest my-vue-app -- --template vue
