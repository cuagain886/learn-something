1. 数组三剑客：map / filter / reduce

方法作用返回值Java Stream 对应
map(fn)把每个元素"变"成另一个值同长度新数组Stream.map()
filter(fn)筛选满足条件的元素新数组（可能更短）Stream.filter()
reduce(fn, init)把所有元素"归约"成一个值单个值（任意类型）Stream.reduce()
💡 核心理念：这三个方法都不会修改原数组（不可变），而是返回新数组。这是函数式编程的基础。

2. 更多实用数组方法

方法作用返回值
find(fn)查找第一个满足条件的元素单个元素 或 undefined
findIndex(fn)查找第一个满足条件的索引索引 或 -1
some(fn)是否有元素满足条件？boolean
every(fn)是否所有元素都满足条件？boolean
flatMap(fn)map + flat(1) 合并扁平化数组
sort(fn)排序（⚠️默认按字符串排！）修改原数组并返回
includes(val)是否包含某值？boolean
join(sep)用分隔符连接所有元素string
slice(start,end)提取子数组（不可变）新数组
splice(start,n)删除/插入（⚠️修改原数组）被删除的元素

3. 不可变 vs 原地修改

✅ 不可变（返回新数组，推荐）⚠️ 原地修改（修改原数组）
map, filter, reduce, find, some, every, slice, concat, flat, flatMappush, pop, shift, unshift, splice, sort, reverse, fill
💡 最佳实践：尽量使用不可变方法。如果需要"修改"数组，用展开运算符创建新数组：const updated = [...arr, newItem]
