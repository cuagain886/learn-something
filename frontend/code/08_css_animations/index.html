4. ⚡ 性能：只动画 transform 和 opacity

浏览器的渲染流水线：Layout → Paint → Composite

✅ transform
只触发 Composite
GPU 加速，60fps
❌ top / left / width
触发 Layout 重排
可能卡顿
属性触发阶段性能建议
transform, opacityComposite only✅ 最佳动画首选
color, backgroundPaint → Composite⚠️ 可接受谨慎使用
width, height, top, left, margin, paddingLayout → Paint → Composite❌ 避免用 transform 替代
