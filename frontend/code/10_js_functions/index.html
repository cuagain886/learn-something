1. 四种定义函数的方式

方式示例特点
函数声明function foo() {}会提升（可以在定义前调用）
函数表达式const foo = function() {};不会提升，赋值给变量
箭头函数const foo = () => {};没有自己的 this（推荐）
方法简写{ foo() {} }对象内的函数

2. 箭头函数 vs 普通函数

特性普通函数箭头函数
语法function(a,b){return a+b;}(a,b) => a+b
this动态绑定（调用时确定）词法绑定（定义时捕获，= 外层 this）
arguments有没有（用 rest 参数替代）
new可以做构造函数不能做构造函数
💡 现代 JS 实践：默认用箭头函数。只有需要动态 this（如事件处理器）或需要使用 new 时才用普通函数。

3. ⚠️ this 绑定规则（与 Java 完全不同！）

JS 的 this 由调用方式决定，不由定义位置决定：

调用方式this 指向
obj.method()obj（点前面的对象）
func()严格模式：undefined；非严格模式：window
new func()新创建的空对象
func.call(obj) / apply / bind显式指定的对象
箭头函数 () => {}定义时所在作用域的 this（词法绑定，不会变！）
⚠️ Java 程序员最常见的坑：把方法作为回调传递时，this 会丢失！解决方法：① 用箭头函数 ② 用 .bind(this)
