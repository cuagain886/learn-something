3. grid-template-areas —— 用 ASCII 画布局！

经典"圣杯"页面布局（header + sidebar + main + footer）

Header
Sidebar（200px）
Main Content（弹性）
Footer

grid-template-areas:
'header header'
'sidebar main'
'footer footer';

💡 在响应式设计中，只需改变 grid-template-areas 和 grid-template-columns，整个布局瞬间变化！

4. 对齐方式速查

属性作用对象方向常用值
justify-items容器 → 所有项目行内（水平）stretch(默认), center, start, end
align-items容器 → 所有项目块级（垂直）stretch(默认), center, start, end
justify-content容器 → 网格整体水平start, center, space-between...
align-content容器 → 网格整体垂直start, center, space-between...
justify-self单个项目水平覆盖 justify-items
align-self单个项目垂直覆盖 align-items
place-itemsjustify-items + align-items 的简写place-items: center = 单元格内居中

5. Grid vs Flexbox —— 一张表说清

维度FlexboxGrid
维度一维（行 或 列）二维（行 和 列）
布局方向内容驱动（content-first）布局驱动（layout-first）
核心概念主轴 + 交叉轴行 + 列 + 网格线
元素大小flex-grow/shrink/basisspan / 固定值 / fr
适用场景组件内部的小布局、导航栏、工具栏页面级大布局、仪表盘、画廊
嵌套使用两者经常嵌套使用！外层 Grid 定大区，内层 Flexbox 排组件
