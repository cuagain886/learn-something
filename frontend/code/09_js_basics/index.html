1. 变量声明：let / const / var

关键字作用域可重复赋值提升建议
let块级 { }✅TDZ（暂时性死区）✅ 可变变量用 let
const块级 { }❌（引用不可变）TDZ✅ 默认用 const
var函数级✅undefined❌ 永远不要用
💡 最佳实践：默认用 const，需要重新赋值时才改用 let。var 是历史遗留，用它会引入难以调试的 bug。

3. == vs === —— 永远的坑

比较结果为什么
0 == "0"true字符串被转换为数字
0 === "0"false类型不同，直接返回 false
"" == 0true空字符串 → 0
null == undefinedtrue规范规定
null === undefinedfalse类型不同
[] == falsetrue[] → "" → 0 → false
⚠️ 铁律：永远用 === 和 !== ，永远不要用 == 和 !=
只有在判断 null/undefined 时可例外：value == null（同时匹配 null 和 undefined）
