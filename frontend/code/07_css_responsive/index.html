📱 响应式设计 —— 一套代码适配所有屏幕

核心思想：移动优先（Mobile First）—— 先写手机版样式，再用 @media (min-width) 逐级增强。

1. 移动优先 vs 桌面优先

策略写法优点
移动优先（推荐） 基础样式 = 手机 → @media (min-width) 逐级增强 代码更少、移动端性能更好、逻辑更清晰
桌面优先 基础样式 = 桌面 → @media (max-width) 逐级降级 老项目常用，移动端加载不必要的桌面样式

2. 相对单位：告别 px 思维

单位相对于使用场景
rem根元素 html 的 font-size字体大小、间距（最推荐）
em父元素的 font-size组件内部的相对缩放
vw / vh视口宽度 / 高度全屏布局、hero 区域
%父元素的对应属性通用比例控制
dvh动态视口高度（移动端扣除地址栏）移动端全屏（比 vh 准）

6. 常用断点速查

设备宽度写法
手机（竖屏）< 640px基础样式（不需要 @media）
手机（横屏）/ 小平板≥ 640px@media (min-width: 640px)
平板≥ 768px@media (min-width: 768px)
桌面≥ 1024px@media (min-width: 1024px)
大屏≥ 1280px@media (min-width: 1280px)

⚠️ 这些断点只是参考，实际项目应该根据内容确定断点，而不是根据设备。当你的内容在某个宽度下看起来"拥挤"时，就在那里加断点。
