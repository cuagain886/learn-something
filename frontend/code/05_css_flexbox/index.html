4. Flexbox vs Grid：什么时候用哪个？

场景推荐原因
导航栏、工具栏Flexbox一维排列，弹性空间
卡片列表（自动换行）Flexboxflex-wrap 自动处理换行
整体页面布局Grid二维控制行列，更清晰
仪表盘/图片画廊Grid需要精确控制行列
表单行内的 label+inputFlexbox一维排列，algin-items 对齐
复杂的响应式布局Gridgrid-template-areas 直观

💡 经验法则：一维用 Flex，二维用 Grid。不确定时先 Flex → 发现需要控制行又控制列时再换 Grid。
