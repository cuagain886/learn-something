  • 这是最后一个 li → :last-child

:nth-child() 示例 —— 斑马条纹表格

#名称说明
1:nth-child(odd)选择所有奇数行
2:nth-child(even)选择所有偶数行
3:nth-child(3n)选择第 3, 6, 9... 行
4:nth-child(3n+1)选择第 1, 4, 7... 行
5:nth-child(-n+3)选择前 3 行
6:nth-last-child(1)选择最后一行（= :last-child）

特指度速查表

写法特指度说明
*0,0,0,0通配符
p0,0,0,1类型选择器
p::first-line0,0,0,2类型 + 伪元素
p.link0,0,1,1类型 + class
#main .item0,1,1,0id + class
style="..."1,0,0,0内联样式
